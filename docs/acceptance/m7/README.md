# Milestone 7 security acceptance

This is a qualification record, not a declaration that a test specification ran. The committed ledger is generated by `just accept-m7` from ignored local logs in `.local/acceptance/m7/`. It records the committed baseline and the uncommitted worktree separately. Re-run after the human commit for committed-tree evidence.

Evidence tiers:

| Tier | Meaning | Where recorded |
| --- | --- | --- |
| A | Deterministic repository, package, stress, and process tests | `acceptance-results.json` and ignored local logs |
| B | Actual booted disposable Fedora Kinoite 44 x86_64 appliance | `appliance-qualification.md` |
| C | Selected physical reference register and kiosk UX | `reference-hardware.md` |
| D | Controlled abrupt interruption of disposable physical hardware | `power-interruption-security.md` |

`passing` requires every mandatory A/B/C/D case to have actual passing evidence. Any executed mandatory failure is `failing`. Missing or blocked evidence is `conditional`; a blocked Tier A group also makes `just accept-m7` exit nonzero. Process SIGKILL is not physical power-loss evidence. Successful x86_64 derivations are not evidence that a deployed appliance booted.

Run `just accept-m7` for the bounded Tier A campaign, `just stress-m7 50000` for optional extended volume, `just acceptance-report-m7` to regenerate from the latest ignored summary, and `just qualify-m7-kinoite` only on an already booted disposable target. Do not run state-changing appliance or physical scenarios on store data.

The root audit CLI's successful `verify` and `list` append `audit.accessed`. The Tier B observation helper therefore uses read-only database validation and leaves root audit CLI access for an explicit manual step. A backup contains credential verifiers and security history; protect it as sensitive state. Restoring an older selected backup can restore an older valid PIN. OS rollback is not a SQLite downgrade, and old binaries must refuse future schema.

This directory does not modify or reinterpret frozen M6 evidence under `docs/acceptance/m6`.
